# Признаки

Одна строка — следующее прослушивание для одного синтетического пользователя.
Ответ skip относится к этому событию. Ни вероятность ответа, ни готовая оценка
соответствия трека пользователю в таблицу не включены.

## Трек
| Колонка | Описание |
|---|---|
| track_genre | 0 — рок, 1 — электронная музыка, 2 — хип-хоп, 3 — эмбиент |
| energy | Энергичность, 0–1 |
| tempo | Темп в условных BPM |
| duration_seconds | Длительность в секундах |
| instrumentalness | Инструментальность, 0–1 |
| valence | Эмоциональная окраска: от мрачной (0) до весёлой (1) |
| familiar_artist | Знаком ли исполнитель, 0/1 |
| explicit_content | Ненормативная лексика, 0/1 |
| language_match | Совпадает ли язык трека с языком пользователя, 0/1 |
| track_age_days | Число дней с момента выхода трека |
| album_track_number | Порядковый номер трека в альбоме |

## История плейлиста
История формируется до текущего события. Её размер ограничен, поэтому доли
неточно отражают предпочтения; дополнительно в наблюдения внесён шум.

| Колонка | Описание |
|---|---|
| history_size | Размер доступной истории |
| playlist_genre_0_share–playlist_genre_3_share | Доли четырёх жанров; сумма равна 1 |
| playlist_top_genre | Жанр с наибольшей долей в наблюдаемой истории |
| playlist_mean_energy | Средняя энергичность музыки в истории |
| playlist_new_artist_share | Доля новых на момент добавления исполнителей |
| playlist_repeat_share | Доля повторных включений треков |
| playlist_long_track_share | Доля длинных треков |
| playlist_instrumental_share | Доля инструментальной музыки |
| playlist_explicit_share | Доля треков с ненормативной лексикой |
| track_plays_7d | Число включений текущего трека за семь дней |
| artist_plays_1h | Число треков этого исполнителя за последний час |
| previous_track_energy | Энергичность предыдущего трека |

## Контекст
| Колонка | Описание |
|---|---|
| listening_context | 0 — фон, 1 — работа/учёба, 2 — тренировка, 3 — дорога, 4 — перед сном, 5 — вечеринка |
| discovery_mode | Режим открытия новой музыки, 0/1 |
| mood_goal | 0 — без особого запроса, 1 — поднять настроение, 2 — успокоиться |
| session_position | Позиция трека в сессии |
| session_elapsed_minutes | Длительность сессии в минутах |
| session_gap_minutes | Перерыв перед текущим прослушиванием в минутах |
| hour, day_of_week | Час (0–23) и день недели (0–6) |
| shuffle_mode | Перемешивание, 0/1 |
| device_code | Категория устройства, 0–3 |
| headphones | Наушники, 0/1 |
| queue_length | Число треков в очереди, включая текущий |
| volume_percent | Установленная громкость проигрывателя, 0–100% |
| stream_bitrate_kbps | Битрейт аудиопотока, кбит/с |
| skip | 1 — пропуск, 0 — продолжение; отсутствует во входе модели |

Коды жанров, контекста и устройства — категории, не числовая шкала.
Производные признаки из выданных колонок разрешены. Число признаков
не ограничено. В конфигурации объявите все исходные колонки, необходимые
для расчёта используемых признаков.
